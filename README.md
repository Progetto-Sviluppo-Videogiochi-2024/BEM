3D horror survival game (demo).
The player must navigate through a cursed forest while avoiding or fighting dangerous creatures, and managing resources.

## 📋 Project Status
For detailed project status and setup information, see [PROJECT_STATUS.md](PROJECT_STATUS.md)

## 🎮 About the Game
**Bloody Easter Monday (BEM)** is a 3D survival horror game where five friends find themselves trapped in a military zone within a cursed forest. After one of them is found dead, the group must find a way to escape while dealing with mysterious creatures and armed military personnel.
